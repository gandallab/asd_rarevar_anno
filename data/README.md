This directory contains raw, static data files that will be used as input for
your analyses. You should provide a mechanism to programatically retrieve them,
such as by a code notebook or Bash script, or, at the very least, describe
where they came from in this README.

Since the files in this directory are assumed to be large, they are ignored by
git by default (see ../.gitignore). Feel free to add exclusions for files that
would be small enough to be hosted by GitHub.
