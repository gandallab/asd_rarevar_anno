This directory contains any output files generated by your analysis notebooks,
such as figures, tables, or serialized data objects.

The files in this directory are not ignored by git by default (see ../.gitignore).
This way, visitors to your Quarto website and GitHub repository can browse the
outputs of your analysis alongside the code. However, you must tell git to
ignore any files in this directory that are too large to be hosted by GitHub
(>100MB) by adding lines to the .gitignore. Visitors should be able to regenerate
large files by cloning the repository and running the code themselves.
